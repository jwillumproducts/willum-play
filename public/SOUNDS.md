# Sounds

Bundled clips are CC0 / public domain. No attribution required. No NC or share-alike licenses.

Each clip is under 30 KB. Safari gets AAC `.m4a` first; other browsers fall back to `.mp3`. Web Audio still unlocks on the first pointer event and respects the in-game mute toggle. If a clip fails to decode, a synthesized fallback plays.
